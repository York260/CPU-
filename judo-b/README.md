# IPPON 柔道對決（judo-b）

一款 3D 柔道格鬥遊戲。和電腦對戰，靠抓把、推拉崩勢、閃避反擊來投倒對手。

這個資料夾是獨立的專案，不會動到儲存庫根目錄的警大學生模擬器，也和另一個版本的 `judo/` 資料夾互不相干。

## 怎麼玩

用瀏覽器直接打開 `judo-b/index.html`。需要網路，3D 引擎（Three.js）是從 CDN 載入的。桌機用鍵盤；手機會自動顯示虛擬搖桿和按鈕。

| 按鍵 | 動作 | 體力 | 說明 |
| --- | --- | --- | --- |
| `W A S D` / 方向鍵 | 移動 | — | 左右靠近或後退，上下繞圈側移 |
| `J` | 抓把 | 10 | 少量傷害（4），並取得組手；投技一定要先抓把 |
| `K` | 大外割 | 24 | 前搖 0.32 秒，傷害 20，對手「後崩」時最有效 |
| `L` | 單臂過肩摔 | 30 | 前搖 0.40 秒，傷害 24，對手「前崩」時最有效 |
| `I` | 捨身小內割 | 20 | 前搖 0.22 秒，傷害 17，能破防守；落空時自己倒地 |
| `Space` | 閃避 | 14 | 前 0.32 秒無敵，並甩開雙方組手 |
| `Shift`（按住） | 防守 | 每秒 9 | 擋得住大外割和過肩摔，擋不住捨身小內割 |
| `P` / `Esc` | 暫停 | | `M` 切換音效 |

## 系統設計

**體力與疲勞**：每個動作都要花體力，不夠就不能出招（體力條會閃紅）。每出一招都會累積疲勞，體力回復速度 = 基礎速度 ÷（1 + 0.12 × 疲勞），所以招式用得越多，體力回得越慢。疲勞只會非常緩慢地消退。體力條下方的紫色條是目前的回復速度。被對手抓住時回復再慢 40%。

**崩し（崩勢）**：抓把之後，往前推，對手會被推著後退，形成「後崩」，適合大外割、捨身小內割；往後拉，對手會被拉著往前，形成「前崩」，適合單臂過肩摔。對手也可以反方向走來抵抗。崩勢成立時，對手頭上會出現提示，招式列也會標出「崩」。

**前搖與反擊**：所有投技都有前搖（身上發光、腳下光環、頭上「!」）。前搖期間閃避成功，可以在 1.3 秒內不用抓把直接投（返し技）；閃掉捨身小內割則有 2 秒，因為對方倒在地上。用防守擋下投技，出招的一方會失衡。兩人同時出招時，先完成前搖的一方投成。

**得分品質**：每次投技依條件計分（崩勢方向正確、返し技或對手失衡、對手體力低於 25、組手抓穩超過 1.5 秒、捨身小內割破防）。

| 品質 | 結果 |
| --- | --- |
| 一般 | 只造成傷害 |
| 好（≥ 0.7） | 技有，傷害 ×1.5；兩次技有＝合技一本 |
| 完美（≥ 1.0） | 一本，直接獲勝（例如返し技加上正確崩勢） |

**比賽規則**（參考 IJF 規則並簡化）：
- 血量歸零算一本。
- 25 秒沒有出投技，或防守姿勢超過 3.5 秒，各給一次指導；三次指導就反則負。
- 時間到先比技有數，相同時血量差 10 以上判優勢勝，否則進入黃金得分，先投成功的人獲勝。
- 每次投技結束，主審喊「待て」，兩人回到開始線。開賽前雙方會先行禮。

**電腦對手**分三個段位，差別在反應速度、防守機率、進攻積極度，以及會不會先推拉製造崩勢再出招：

| 段位 | 反應 | 防守機率 |
| --- | --- | --- |
| 初段 | 0.45 秒 | 28% |
| 三段 | 0.30 秒 | 55% |
| 國手 | 0.20 秒 | 78% |

**練習模式**：沒有時間限制和指導，對手只會移動、抓把和防守，不會投你；血量歸零會自動補滿，畫面上方會輪流顯示操作提示。

## 技術說明

- 整個遊戲是單一 HTML 檔，只用 Three.js（r160），角色、場館、音效都由程式產生，沒有外部素材。
- 投技動畫是雙人關鍵影格編排，用 Hermite 曲線插值；落地的影格會加速撞擊、瞬間停住。
- 投技演出包含慢動作、電影運鏡、殘影、衝擊波、粉塵、畫面震動、打擊停頓，以及直書招式名稱。
