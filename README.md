# 警大學生模擬器

一款以中央警察大學為背景的文字選擇遊戲。建立角色後，從預備教育一路走到警察特考，在每個事件中做出選擇。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。進度會自動存在瀏覽器裡，下次打開可以繼續。

## 遊戲內容

**六個階段**

| 階段 | 內容 |
| --- | --- |
| 預備教育 | 報到、豆腐乾棉被、早點名、3000 公尺、想家的夜、結訓 |
| 一年級 | 社團、學長制、刑法期中、衛哨、聯誼…… |
| 二年級 | 帶學弟妹、射擊、救生游泳、校慶分列式…… |
| 三年級 | 派出所暑期實習、家暴報案、紅包誘惑、颱風救災…… |
| 四年級 | 畢業實習、特考準備、畢業旅行、畢業典禮 |
| 特考 | 衝刺、考前感冒、申論題、放榜 |

一到四年級每年會從事件池中隨機抽出 4 件，所以每次遊玩的經歷都不同。

**角色建立**：姓名、性別、13 個學系（決定特考類科與分發單位）、5 種出身背景，數值另有 ±5 的隨機值。

**五項能力**：體能、課業、操行、心情、人緣。有些選項需要判定，成功率依相關能力計算，並會在選項旁顯示。每項能力依數值區間（100、80、60、40、20 以上與 19 以下）顯示稱號，例如體能 100 為「宙斯之子」。

**獎懲制度**：嘉獎／小功／大功與申誡／小過／大過，功過可以相抵。相抵後滿三大過即遭退學。

**狀態詞條**：學生幹部、交往中、舊傷、社團等詞條會出現在學生證上，點擊可查看介紹與效果（例如判定成功率加減、每階段心情變化）。

**學年考核**：每學年末檢查學科、體能、操行，標準逐年提高。不及格要補考，補考未過累計兩次即退學。

**結局**：退訓、休學、獎懲退學、課業退學、特考落榜、通過特考、特考榜首，共 7 種。通過特考時會依學系、最高能力與一路上的經歷，產生專屬的派令與後日談。

> 本遊戲為虛構作品，事件與制度經過簡化，與實際校規不盡相同。

## 卡片編輯器

> 目前暫時關閉（不顯示入口）。要恢復時，把 `index.html` 裡的 `EDITOR_ENABLED` 改成 `true`。

點右上角的「卡片編輯器」（或在網址後加上 `#editor`），可以依階段瀏覽所有事件卡片。每張卡片會直接顯示每個選項的判定、成功與失敗結果、數值變化、獎懲和詞條。

點一張卡片就能在右側面板修改：標題、時間、地點、情境描述；選項文字、警示標籤、排序、新增或刪除；能力判定的能力與難度（會即時顯示成功率）；以及每個結果的描述、五項能力、六種獎懲、取得或移除的詞條、特考加分、加入社團、退訓。

- 在 claude.ai 上開啟時，修改會存進共享資料庫，所有有權限的人看到同一份，遊戲也會立刻使用新內容。
- 直接打開本機檔案時，修改只存在該瀏覽器。
- 「匯出修改」會輸出所有修改過的卡片 JSON，交給開發者就能寫回程式碼。
- 學年考核卡由程式計算，不能在編輯器修改。

## 意見回饋

拿到連結的人都可以回饋，三個入口：頁首的「意見回饋」、事件卡與結果卡下方的「回報這張卡」、結局頁的「意見回饋」。

在遊戲裡填「提案」「BUG 或機制漏洞」「你是誰（選填）」，按「送出」會在新分頁直接提交到 Google 表單，顯示「已收到回覆」即完成。從「回報這張卡」送出時，有填寫的欄位前面會自動加上卡片代號和標題，例如「〔y1b 刑法總則期中考〕」。

## 柔道對決（試作）

獨立的 3D 柔道戰鬥系統試作，位於 `judo/index.html`，直接用瀏覽器打開即可（需要網路載入 three.js）。

- 白色道服是玩家，藍色道服是 AI；開始與結束都會互相敬禮，裁判宣告「始め」後開打。
- 左下搖桿移動（以畫面方向為準，往右推就往畫面右邊走），右下技能鍵；電腦可用 WASD／方向鍵與 J、K、L。
- 遊戲鏡頭：永遠對準兩人中點、從兩人連線的側面看，繞圈時緊跟著轉（約 0.25 秒追上，轉速上限約每秒 200 度）；兩人越遠拉得越遠，並依螢幕比例調整（手機直式也裝得下）。移動平滑有慣性；兩人互換位置時不會突然翻到另一邊。抓把成功時鏡頭快速晃一下。壓制中鏡頭角度固定。裁判會走到兩人另一側，擋到鏡頭時自動淡出。
- 待て後回到開始線時，白（玩家）一定在畫面左邊：依兩人當時左右選開始線，不會穿過對方，鏡頭再轉到對應的一側。
- 未抓把：抓把、閃避。抓把後：防禦，以及上場前從五種投技中挑選帶上的三招（封面有各招說明；AI 每場隨機帶三招）。
- 崩し：抓把後推拉搖桿改變對手重心。推 → 對手後傾 → 綠色前方技（捨身小內割、大外割）；推後突然放開或拉回 → 對手前傾 → 金色後方技（丟體、單臂過肩摔、大腰）。前後以出招者的推拉方向來分。按鈕即時顯示成功率。
  - 捨身小內割：輕微後傾即可，多半有效，失敗自己倒地可能被壓制。
  - 丟體：抓把時繞圈移動有加成。
  - 單臂過肩摔：需明顯前傾，容易一本。大腰：成功率極低，最容易一本。
- 投技結果分有效、半勝、一本；摔倒後可選壓制技：袈裟固、上四方固（方向攻防）。壓制 5 秒有效、10 秒半勝、20 秒一本。
  - 袈裟固：水平計量器，標從中間開始，雙方連打（或搖手機）比快，點得快的一方把標往前推；被壓者推到底就掙脫。玩家永遠往右推。標很靈敏，每一下都會明顯前後擺盪。掙扎時兩人會繞著被壓者胸口緩緩旋轉，被壓者點得越快轉得越快。AI 連打速度：新手每秒約 4.2 下、國手 5.2 下、世界冠軍 6.2 下，而且忽快忽慢。
- 前迴轉倒法：被丟體、單臂過肩摔、大腰摔成「有效」時，有時（約六成）會出現機會；半勝以上來不及滾。時機到時畫面稍微變慢、頭上出現藍色「前迴轉！」、畫面邊緣微微發藍並有提示音，此時按技能鍵（顯示「現在！」）就能滾翻卸力，不算分，對手也不能接壓制；AI 也會依難度使用。
- 投技演出：每招依柔道原理分成崩し、作り、掛け、落地，雙方動作同一時間軸配合，影格以曲線串接不停頓，落地加速後停得乾脆。
  - 依得分分三級，一本最強：

    | | 有效 | 半勝 | 一本 |
    | --- | --- | --- | --- |
    | 掛け瞬間 | 字卡 | 大招閃 0.14 秒 | 大招閃 0.32 秒（聚光、放射線、鏘聲） |
    | 升空 | 頂點附近稍慢 | 0.25 倍慢動作 | 0.14 倍慢動作 |
    | 空中定格 | 無 | 1.6 秒，鏡頭環繞 360 度 | 2.4 秒，鏡頭由低到高環繞 360 度，心跳聲 |
    | 落地 | 直接落地 | 加速砸地、低角度鏡頭 | 加速砸地、貼地鏡頭 |
    | 衝擊 | 停格 0.07 秒、火花 | 停格 0.14 秒、雙衝擊波 | 停格 0.26 秒、畫面反白、光柱、地面裂痕、三重衝擊波 |

  - 鏡頭：起手側拍全身，施技時低角度追著兩人重心，定格時繞著空中的兩人轉（像大賽轉播的重播），落地後往上拉開，再從同一側平順交還遊戲鏡頭。
  - 特效：每招有代表色（大外割翠綠、小內割青、丟體橘、過肩摔紅、大腰紫），殘影、衝擊波、火花、閃光、濾鏡和招式字卡都用這個顏色；字卡在左上角、落地後淡出，宣告字在記分板下方，不擋動作。
  - 預兆：出招前，出招者腳下有代表色的收縮光環，對手出招時頭上的「!」會標出招名。
  - 聲音：起手道服聲、施技風聲、升空時觀眾驚呼、落地重擊，以及依得分大小的掌聲／歡呼／全場沸騰。
- 指導：太久不出招（30 秒）、太久沒抓把（15 秒沒伸手抓）、抓把後只防守不進攻（約 12 秒，一直按防禦累積更快）、出場外；快被判時會先提示。另有合わせ技一本、黃金得分，三種 AI 難度。
- 封面可開關重心計；袈裟固連打有跳字、連擊數、音效與震動回饋。
- 打擊回饋：出招、失敗、被擋、摔倒、被摔、壓制攻防都有震動（Android 可用，iPhone 瀏覽器不支援）、畫面邊緣閃光、鏡頭晃動與音效；封面可關閉震動。
