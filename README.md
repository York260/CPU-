# 警大學生模擬器

一款以中央警察大學為背景的文字選擇遊戲。建立角色後，從預備教育一路走到警察特考，在每個事件中做出選擇。

## 怎麼玩

直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西。進度會自動存在瀏覽器裡，下次打開可以繼續。

## 遊戲內容

**六個階段**

| 階段 | 內容 |
| --- | --- |
| 預備教育 | 報到、豆腐乾棉被、早點名、3000 公尺、想家的夜、結訓 |
| 一年級 | 社團、學長制、刑法期中、衛哨、聯誼…… |
| 二年級 | 帶學弟妹、射擊、救生游泳、校慶分列式…… |
| 三年級 | 派出所暑期實習、家暴報案、紅包誘惑、颱風救災…… |
| 四年級 | 畢業實習、特考準備、畢業旅行、畢業典禮 |
| 特考 | 衝刺、考前感冒、申論題、放榜 |

一到四年級每年會從事件池中隨機抽出 4 件，所以每次遊玩的經歷都不同。

**角色建立**：姓名、性別、13 個學系（決定特考類科與分發單位）、5 種出身背景，數值另有 ±5 的隨機值。

**五項能力**：體能、課業、操行、心情、人緣。有些選項需要判定，成功率依相關能力計算，並會在選項旁顯示。每項能力依數值區間（100、80、60、40、20 以上與 19 以下）顯示稱號，例如體能 100 為「宙斯之子」。

**獎懲制度**：嘉獎／小功／大功與申誡／小過／大過，功過可以相抵。相抵後滿三大過即遭退學。

**狀態詞條**：學生幹部、交往中、舊傷、社團等詞條會出現在學生證上，點擊可查看介紹與效果（例如判定成功率加減、每階段心情變化）。

**學年考核**：每學年末檢查學科、體能、操行，標準逐年提高。不及格要補考，補考未過累計兩次即退學。

**結局**：退訓、休學、獎懲退學、課業退學、特考落榜、通過特考、特考榜首，共 7 種。通過特考時會依學系、最高能力與一路上的經歷，產生專屬的派令與後日談。

> 本遊戲為虛構作品，事件與制度經過簡化，與實際校規不盡相同。

## 卡片編輯器

> 目前暫時關閉（不顯示入口）。要恢復時，把 `index.html` 裡的 `EDITOR_ENABLED` 改成 `true`。

點右上角的「卡片編輯器」（或在網址後加上 `#editor`），可以依階段瀏覽所有事件卡片。每張卡片會直接顯示每個選項的判定、成功與失敗結果、數值變化、獎懲和詞條。

點一張卡片就能在右側面板修改：標題、時間、地點、情境描述；選項文字、警示標籤、排序、新增或刪除；能力判定的能力與難度（會即時顯示成功率）；以及每個結果的描述、五項能力、六種獎懲、取得或移除的詞條、特考加分、加入社團、退訓。

- 在 claude.ai 上開啟時，修改會存進共享資料庫，所有有權限的人看到同一份，遊戲也會立刻使用新內容。
- 直接打開本機檔案時，修改只存在該瀏覽器。
- 「匯出修改」會輸出所有修改過的卡片 JSON，交給開發者就能寫回程式碼。
- 學年考核卡由程式計算，不能在編輯器修改。

## 意見回饋

拿到連結的人都可以回饋，三個入口：頁首的「意見回饋」、事件卡與結果卡下方的「回報這張卡」、結局頁的「意見回饋」。

在遊戲裡填「提案」「BUG 或機制漏洞」「你是誰（選填）」，按「送出」會在新分頁直接提交到 Google 表單，顯示「已收到回覆」即完成。從「回報這張卡」送出時，有填寫的欄位前面會自動加上卡片代號和標題，例如「〔y1b 刑法總則期中考〕」。
